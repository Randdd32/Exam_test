# Веб-приложение для экзамена (React + Spring Boot)

Клиент-серверное веб-приложение (SPA + REST API), спроектированное с учетом требований к экзамену.

## Стек технологий

- **Backend:** Java 17, Spring Boot 3.2, Spring Security, Spring Data JPA (Hibernate), JWT, Caffeine Cache (для blacklist токенов).
- **База данных:** H2 Database (Встроенная, работает в файловом режиме — данные сохраняются между перезапусками).
- **Frontend:** TypeScript, React 19, Vite, Zustand (управление состоянием), React Router v7, TanStack Query (кэширование и запросы), React Hook Form + Zod (инлайн-валидация), Axios.

## Архитектура ролей

В системе реализовано 3 уровня доступа:

1. **Гость (Неавторизованный):** публичная шапка с кнопками "Вход" и "Регистрация" (модальные окна). Доступ к публичному списку объектов _(если это предусмотрено билетом)_.
2. **Пользователь (USER):** Авторизованный профиль. Может управлять своими данными (Страница А) и редактировать пароль.
3. **Администратор (ADMIN/SUPERADMIN):** В выпадающем меню профиля доступна кнопка "Панель администратора". При переходе открывается боковой сайдбар для управления пользователями и сущностями.

## 🚀 Инструкция по запуску

Проект запускается локально без использования Docker.

### 1. Настройка переменных окружения (Backend)

Для корректной работы системы безопасности необходимо задать секретный ключ JWT и время жизни токенов. Вы можете задать их прямо в файле `backend/src/main/resources/application.yml` или прокинуть через среду вашей ОС / IDE.

**Список параметров:**

- `JWT_SECRET` — Базовый 256-битный ключ (Base64). По умолчанию: `rDuFODTRZ/2qQIlDWO+Yk1sde/+qRKckhoxwOcaa3dI=`
- `JWT_ACCESS_EXPIRATION_MINUTES` — Время жизни Access токена (в минутах). По умолчанию: `30`
- `JWT_REFRESH_EXPIRATION_DAYS` — Время жизни Refresh токена (в днях). По умолчанию: `60`

_Примечание: Если вы не зададите эти переменные, Spring Boot использует значения по умолчанию, прописанные в `application.yml`._

### 2. Запуск Backend-сервера

_Требования: JDK 17._

1. Откройте терминал в папке `backend`.
2. Запустите Spring Boot с профилем `local` с помощью Maven Wrapper:
   - **На Windows:**
     ```cmd
     mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=local
     ```
   - **На Linux / macOS:**
     ```bash
     ./mvnw spring-boot:run -Dspring-boot.run.profiles=local
     ```
3. Сервер запустится на порту `8080`.
   - Консоль базы данных H2 доступна по адресу: http://localhost:8080/h2-console
   - _(URL: `jdbc:h2:file:./app-db`, User: `sa`, Password: `password`)_

### 3. Запуск Frontend-клиента

_Требования: Node.js (версия 18+)._

1. Откройте новый терминал в папке `frontend`.
2. Установите зависимости (требуется только один раз):
   ```bash
   npm install
   ```
3. Запустите сервер для разработки::
   ```bash
   npm run dev
   ```
4. Приложение будет доступно по адресу: http://localhost:5173
